## Why Git Makes Development Easier
Git safeguards code by keeping a history of changes. Developers can review previous versions and understand what changed over time.

Git also makes collaboration easier because team members can work on the same project, commit their changes, and share them through a remote repository such as GitHub.

## Git Workflow
The basic workflow is edit, add, commit, and push.
